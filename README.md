# Daymark

A lightweight to-do list that runs in your browser. Tasks are saved in the browser on your device.

## Run it

Open `index.html` in a web browser. No installation, build step, or server is required.

## Use it

- Add a task and choose its priority.
- Mark tasks complete, or filter the list by all, to-do, and done.
- Delete individual tasks or clear all completed tasks.
- Your list is saved automatically in your browser's local storage.

## Data

Tasks stay in the browser profile where they were created. Clearing that browser's site data may remove them; they are not synced between devices.
